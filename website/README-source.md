# Viral source and English presentation data

Viral's initial website and data were adapted from [yjr927/idore_tools](https://github.com/yjr927/idore_tools). The separate VIRO repository was empty when cloned.

The JSON documents in `data/` preserve the source schema, identifiers, status enums, URLs, revisions, timestamps, numeric metrics, and ordering. Human-readable Chinese titles, observations, historical notes, and service messages have been translated into English. Historical statements remain observations from their recorded dates, not claims of current popularity or newly verified evidence.

The copied data contains 12 discovery candidates, three production records, two saved creations, and one character. Existing limitations remain visible: OpenAI reported `insufficient_quota`, and TikTok account upload authorization was not configured in this snapshot. Translation does not run a generator, refresh an observation, or authorize an upload.

The source repository remains the origin for the production workflows and original records. Local English data is a presentation snapshot; any later source refresh must retain the English presentation and the source's evidence qualifications.
